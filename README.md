🚀 Pipeline Builder (React + React Flow)

📌 Overview

This project is a visual pipeline builder where users can:

- Drag and drop nodes (Input, LLM, Output, Text)
- Connect nodes visually
- Validate pipeline structure

🛠 Tech Stack

- React.js
- React Flow
- Zustand (state management)

✨ Features

- Drag-and-drop UI
- Custom nodes (Input, LLM, Output, Text)
- Connect nodes with edges
- Pipeline validation (checks connections)

🚀 How to Run

npm install
npm start

💡 What I Learned

- Working with React Flow
- Managing state using Zustand
- Building interactive UIs
